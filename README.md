# Blocos — Sandbox 2D

Protótipo de jogo sandbox de construção e mineração, executado no navegador com JavaScript e HTML5 Canvas.

## Jogar
Abra `index.html` localmente ou publique o repositório com GitHub Pages.

## Controles
- **A / D** ou setas: mover
- **Espaço**, W ou seta para cima: pular
- **1–6**: selecionar bloco
- **Clique esquerdo**: minerar
- **Clique direito**: colocar bloco
- **Salvar mundo**: guardar progresso no armazenamento local do navegador

## Tecnologias
HTML5, CSS e JavaScript puro, sem dependências externas.

Projeto independente e original inspirado no gênero sandbox de blocos; não inclui recursos, marcas ou código proprietário do Minecraft.
